## 🏆 Featured Project

### 📡 TFG-dashboard-5G
**Analysis and Management of Network Services over Open-Source 5G Infrastructures**
> *Final Degree Project — Grade: 10/10 with Honours nomination*

Designed and deployed a private 5G network on physical hardware using **srsRAN Project** (RAN) and **Open5GS** (5G Core) running in Docker containers. Built a real-time web-based monitoring and management tool using Python and Prometheus, with security controls including authentication, least privilege and input sanitisation. Validated end-to-end connectivity through real UE registration on the deployed network.

**Technologies:** srsRAN · Open5GS · Docker · Prometheus · Python · Bash · Linux · SDR

🔗 [View repository](https://github.com/j-barco/TFG-dashboard-5G)
